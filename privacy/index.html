서비스 이름

No Money No Honey

개인정보 수집 여부

No Money No Honey는 사용자의 이름, 이메일, 전화번호, 주소, 위치정보, 연락처, 건강 정보, 결제 정보, 광고 식별자를 개발자 서버로 수집하지 않습니다.

현재 앱은 계정 로그인 기능과 서버 동기화 기능을 제공하지 않습니다.

앱 데이터 저장 위치

사용자가 입력한 포트폴리오, 보유 종목, 현금 잔액, 예금/적금, 매수/매도/배당/이자 기록, 매매 회고, 설정 정보는 사용자의 기기 안에 저장됩니다.

iPhone과 iPad 앱은 Capacitor SQLite 기반 로컬 저장소를 사용합니다. 개발자는 사용자의 포트폴리오 데이터를 자동으로 수집하거나 별도 서버로 전송하지 않습니다.

앱 잠금과 Face ID

iPhone과 iPad에서 사용자가 앱 잠금을 켜면 4자리 암호의 검증값과 잠금 설정은 해당 기기의 ThisDeviceOnly Keychain에만 저장되며, NMNH 백업 파일과 iCloud Drive 백업에 포함되지 않습니다. 개발자는 앱 잠금 암호나 검증값을 수집하거나 서버로 전송하지 않습니다.

사용자가 Face ID를 켜면 인증은 Apple의 LocalAuthentication 기능이 기기 안에서 처리합니다. 앱과 개발자는 얼굴 이미지나 생체정보를 받거나 저장하지 않습니다. 앱이 비활성화된 동안에는 앱 전환기 화면에서 포트폴리오 내용을 가리기 위한 privacy cover를 표시할 수 있습니다.

구독과 결제

NMNH 멤버십 구독 결제와 결제 관리는 Apple App Store의 StoreKit 및 Apple ID 구독 시스템을 통해 처리됩니다. 개발자는 사용자의 카드번호나 결제 수단 정보를 직접 수집하거나 저장하지 않습니다.

외부 네트워크 요청

앱은 주식 가격, 암호화폐 가격, 종목 검색, USD/KRW 환율 정보를 가져오기 위해 외부 네트워크 요청을 할 수 있습니다.

외부 요청에는 사용자가 검색한 종목명, 종목코드, 시장 정보 등이 포함될 수 있습니다. 이 정보는 가격과 환율 조회를 위해 사용되며, 개발자가 별도로 저장하지 않습니다.

  • 주식 가격 및 종목 검색 데이터
  • 암호화폐 가격 데이터
  • 국내 종목 목록 데이터
  • USD/KRW 환율 데이터

외부 데이터 제공자의 개인정보 처리 방식은 각 제공자의 정책을 따릅니다.

백업과 복원

앱은 사용자가 직접 만든 백업 파일을 저장하거나, 백업 파일에서 데이터를 복원할 수 있습니다.

iPhone과 iPad 앱은 앱 Documents 영역의 nmnh-backups 폴더에 백업 파일을 저장하고, 앱 안에서는 최신 백업 파일을 복원합니다. 백업 파일에는 포트폴리오 데이터가 포함될 수 있으므로 사용자가 안전하게 보관해야 합니다.

현재 앱은 자체 서버 기반 동기화 기능을 제공하지 않습니다. 사용자가 백업 파일을 iCloud Drive 같은 외부 저장 위치로 직접 이동하는 경우, 해당 저장소의 개인정보 처리 방식은 각 서비스의 정책을 따릅니다.

데이터 삭제

사용자는 앱 안에서 포트폴리오, 보유 종목, 예금/적금, 매수/매도/배당 기록과 매매 회고를 삭제할 수 있습니다.

앱을 삭제하면 기기에 저장된 앱 데이터도 삭제될 수 있습니다. 사용자가 별도로 저장한 백업 파일은 직접 삭제해야 합니다.

아동 개인정보

No Money No Honey는 아동의 개인정보를 의도적으로 수집하지 않습니다.
