서비스 이름

No Money No Honey

개인정보 수집 여부

No Money No Honey 개발자는 사용자의 이름, 이메일, 전화번호, 주소, 위치정보, 연락처, 건강 정보, 결제 정보, 광고 식별자를 개발자 서버로 수집하지 않습니다. 사용자가 부동산 관리 자산에 선택 입력한 주소는 앱 데이터로만 처리합니다.

현재 앱은 계정 로그인 기능과 서버 동기화 기능을 제공하지 않습니다.

포트폴리오 데이터 저장 위치

사용자가 입력한 포트폴리오, 보유 종목, 포트폴리오 현금, 독립 현금성 자산과 날짜별 잔액, 매수/매도 기록, 매매 회고, 실물·기타 관리 자산과 평가 이력, 부동산의 선택 주소, 개별채권 정보, 부채와 날짜별 잔액 이력, 설정 정보는 사용자의 기기 안에 있는 로컬 SQLite 데이터베이스 또는 모바일 앱 데이터에 저장됩니다.

부채에는 사용자가 선택 입력한 대출 유형, 대출 이름, 금융기관·대여자, 계좌·계약 식별 메모, 원금·금리·상환일 같은 대출 상세와 날짜별 잔액이 포함될 수 있습니다. 이러한 정보도 로컬 앱 데이터로만 처리하며 개발자가 자동 수집하거나 개발자 서버로 전송하지 않습니다.

개발자는 이 데이터를 자동으로 수집하거나 서버로 전송하지 않습니다.

화면녹화 보유 가져오기

iPhone의 화면녹화로 가져오기는 사용자가 iOS 시스템 사진 선택기에서 직접 고른 영상 한 개만 처리합니다. 앱은 사진 보관함 전체 접근 권한을 요구하지 않으며, 선택한 영상에서 종목·수량과 선택적 평균단가·평가금액·수익률 후보를 찾는 작업은 Apple의 AVFoundation과 Vision 기능을 사용해 기기 안에서 수행합니다.

선택한 영상, 추출한 화면, OCR 원문과 계좌번호처럼 보이는 문구는 개발자 서버나 외부 분석 서비스로 전송하지 않고 NMNH 데이터베이스·백업에도 저장하지 않습니다. 임시 영상은 처리 성공·실패·취소 뒤 삭제하며, 사용자가 원본 화면과 대조해 확인한 종목·수량·선택값만 기존 로컬 포트폴리오 데이터로 저장합니다.

앱 잠금과 Face ID

iPhone/iPad에서 사용자가 앱 잠금을 켜면 4자리 암호의 검증값과 잠금 설정은 해당 기기의 ThisDeviceOnly Keychain에만 저장되며 NMNH 백업 파일과 iCloud Drive 백업에 포함되지 않습니다. 개발자는 앱 잠금 암호나 검증값을 수집하거나 서버로 전송하지 않습니다.

사용자가 Face ID를 켜면 인증은 Apple의 LocalAuthentication 기능이 기기 안에서 처리합니다. 앱과 개발자는 얼굴 이미지나 생체정보를 받거나 저장하지 않습니다. 앱이 비활성화된 동안에는 앱 전환기 화면에서 포트폴리오 내용을 가리기 위한 privacy cover를 표시할 수 있습니다.

외부 네트워크 요청

앱은 주식 가격, 암호화폐 가격, 종목 검색, 환율 정보와 사용자가 선택한 실물 금의 KRX 금시장 종가 참고가를 가져오기 위해 외부 네트워크 요청을 할 수 있습니다.

외부 요청에는 사용자가 검색한 종목명, 종목코드, 시장 정보 등이 포함될 수 있습니다. 이 정보는 가격과 환율 조회를 위해 사용되며, 앱 개발자가 별도로 저장하지 않습니다.

사용자가 자동 새로고침이나 장마감 스냅샷 보완 기능을 켠 경우, 앱은 사용자가 직접 검색 버튼을 누르지 않아도 보유 중인 종목/코인 가격과 환율을 갱신하기 위한 같은 성격의 외부 요청을 실행할 수 있습니다. iOS에서는 사용자가 장마감 자동 스냅샷을 켜고 Background App Refresh가 허용된 경우에도 같은 성격의 가격 조회가 실행될 수 있습니다. 이 요청 결과와 자산 스냅샷은 사용자의 기기 안에 저장되며 개발자 서버로 전송되지 않습니다.

앱은 운영자가 작성한 공지, 개발자노트, 투자대가의 포트폴리오 같은 읽기 전용 콘텐츠를 가져오기 위해 정적 호스팅 페이지에 요청할 수 있습니다. 이 요청은 콘텐츠 JSON 파일을 내려받는 용도이며, 사용자의 포트폴리오 데이터, 보유 종목, 거래 기록, 백업 파일을 운영자 서버로 전송하지 않습니다. 정적 호스팅 제공자는 일반적인 웹 요청 처리 과정에서 IP 주소, User-Agent 같은 네트워크 메타데이터를 처리할 수 있습니다.

실물 금의 공인 참고 평가를 선택하면 앱은 같은 읽기 전용 호스팅의 금 종가 endpoint에 GET 요청을 보냅니다. 이 요청에는 사용자의 자산명, 중량, 순도, 평가액, 포트폴리오, 거래 기록 또는 백업 데이터가 포함되지 않습니다.

보유기업 공시를 열면 앱은 최근 국내 상장회사 공개 공시 목록을 읽기 전용 endpoint에서 받고, 사용자의 국내 보유 종목과의 일치는 기기 안에서 계산합니다. 전체 공시 요청에는 포트폴리오 ID·이름, 보유 목록, 거래 기록이 포함되지 않습니다. 사용자가 한 기업의 공식 재무 요약을 직접 열 때만 공개된 회사 코드, 사업연도와 보고서 구분값을 보냅니다. 제공자는 일반적인 웹 요청 처리 과정에서 IP 주소와 User-Agent 같은 네트워크 메타데이터를 처리할 수 있습니다.

현재 코드 기준으로 사용하는 외부 데이터 소스는 다음 성격의 서비스입니다.

  • 주식 가격 및 종목 검색 데이터
  • 암호화폐 가격 데이터
  • 국내 종목 목록 데이터
  • USD/KRW 환율 데이터
  • 공공데이터 기반 KRX 금시장 종가 참고 데이터
  • 금융감독원 OpenDART 공개 공시·재무 데이터
  • 앱 운영 공지와 읽기 전용 참고 콘텐츠

외부 데이터 제공자의 개인정보 처리 방식은 각 제공자의 정책을 따릅니다.

홈 화면 위젯

홈 화면 위젯은 기기 내 App Group에 요약 표시값, 공개 시세 조회용 종목 식별자, 최소 집계 수량·원가·고정 자산/부채 기여분과 최대 7일의 계산 입력을 보관합니다. 파일은 기기 보호를 적용하고 백업에서 제외합니다. 원본 거래 목록, 원장 ID, 계좌·사용자 ID, 메모와 백업 파일을 위젯에 복사하지 않습니다.

iOS 17 이상에서는 위젯의 새로고침 버튼이나 시스템이 허용한 위젯 실행 중 기존 시세·환율 제공자에 공개 종목·시장 정보만 요청할 수 있습니다. 수량·원가·금액·포트폴리오 이름·사용자 식별자는 외부 요청이나 로그에 포함하지 않으며 재계산은 기기 안에서 수행합니다. 원본 자산 기록은 위젯에서 변경하지 않습니다. 위젯 금액 숨기기를 켜면 공유 금액과 계산 입력·시세 cache를 제거합니다. 앱 잠금과 위젯 금액 숨김은 별도 설정입니다.

백업과 복원

앱은 백업 파일을 저장하거나 백업 파일에서 데이터를 복원할 수 있습니다. 데스크톱 앱은 사용자가 선택한 위치에 백업 파일을 저장하고, 사용자가 선택한 백업 파일을 복원합니다. iPhone/iPad 앱은 앱 Documents 영역의 nmnh-backups 폴더에 백업 파일을 저장하고, 앱 안에서는 최신 백업 파일을 복원합니다.

iPhone/iPad 앱은 사용자가 iCloud에 백업 저장을 직접 실행한 경우 같은 모바일 백업 JSON 파일을 앱의 iCloud Documents 컨테이너에 저장할 수 있습니다. iCloud 최신 백업 복원은 iCloud Drive에 있는 최신 NMNH 백업 파일을 읽고, 현재 데이터를 교체하기 전에 현재 데이터의 안전 백업을 앱 Documents 영역에 먼저 저장합니다.

백업 파일에는 포트폴리오 데이터, 독립 현금성 자산과 날짜별 잔액, 실물·기타 관리 자산, 개별채권, 사용자가 입력한 부동산 주소, 금융기관·대여자와 대출 상세를 포함한 부채 및 날짜별 잔액 이력이 포함될 수 있으므로, 사용자는 백업 파일을 안전한 위치에 보관해야 합니다.

현재 iCloud Drive 백업은 사용자가 버튼을 눌러 저장하고 최신 파일을 복원하는 수동 파일 백업입니다. CloudKit 레코드 동기화, 실시간 기기 간 자동 동기화, 자동 병합은 제공하지 않습니다. iCloud Drive에 저장된 백업 파일의 보관과 동기화는 사용자의 Apple ID, iCloud Drive 설정, Apple iCloud 정책의 영향을 받습니다.

공유 이미지

앱은 사용자가 선택한 포트폴리오 구성을 공유 이미지로 만들 수 있습니다.

공유 이미지는 사용자의 기기 안에서 생성되며, 개발자 서버로 전송되지 않습니다.

사용자가 iPhone 공유 시트에서 메시지, SNS, 파일 저장, 이미지 저장 같은 대상을 직접 선택하면, 해당 공유 대상의 개인정보 처리 방식과 저장 위치는 사용자가 선택한 앱 또는 Apple 시스템 기능의 정책을 따릅니다.

공유 이미지에는 사용자가 미리보기에서 표시하도록 선택한 포트폴리오 이름, 구성 비중, 수익률, 금액 정보 등이 포함될 수 있습니다.

데이터 삭제

사용자는 앱 안에서 포트폴리오, 보유 종목, 매수/매도 기록과 매매 회고를 삭제할 수 있습니다.

독립 현금성 자산은 0원 잔액을 확인한 뒤 보관할 수 있고, 보관해도 날짜별 잔액 이력을 유지하며 다시 복구할 수 있습니다. 실물·기타 관리 자산과 개별채권도 보관 후 평가 이력을 유지합니다. 부채는 최신 잔액이 0원으로 확인된 뒤에만 보관할 수 있고, 보관해도 대출 상세와 날짜별 잔액 이력은 유지되며 다시 복구할 수 있습니다. 따라서 보관은 삭제와 같지 않습니다.

앱을 삭제하거나 로컬 데이터베이스 파일을 삭제하면 기기에 저장된 앱 데이터도 삭제될 수 있습니다. 단, 사용자가 별도로 저장한 백업 파일은 직접 삭제해야 합니다.
